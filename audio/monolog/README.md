# Монолог «Они снова поют» — проба VoiceStudio

Оригинальный текст (`tekst.txt`), ~63 с. Голос: VoiceStudio 0.5.7, движок VoxCPM2 (Apache-2.0),
голос по описанию «глубокий тёплый мужской баритон, ~45 лет, ветеран, медленно и сдержанно».
Сгенерирован по абзацам: первый — по описанию, остальные — клоном первого (модель выдаёт ≤30 с за раз).
Рендер на CPU без GPU: ~17 минут вычислений на 50 с речи.
Подложка (струнные, фортепиано, птицы в финале) синтезирована локально.

- `monolog_golos.mp3` — только голос
- `monolog_s_muzykoy.mp3` — голос с музыкой
