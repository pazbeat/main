# donk на Dust2: модель поведения по демкам

Пайплайн: 5 демок Spirit на Dust2 (IEM Cologne Major 2026) → demoparser2 → признаки состояния игры → LightGBM.

Запуск (из этой папки, данные пишутся в `data/`):

1. `python3 extract.py` — скачивает демки с Hugging Face (cs2povarchive/cs2-demos), парсит тики 16 Гц и события, удаляет .dem.
2. `python3 features.py` — признаки для всех игроков.
3. `python3 stats.py` — статистика стрельбы donk.
4. `python3 train.py` — модели позиции (+1 с, +2 с), поворота прицела и выстрела; проверка «один матч отложен».
5. `python3 export.py` — данные для страницы; затем подставить `data/page.json` в `page_tpl.html` вместо `__DATA__`.

Результат (медиана ошибки позиции через 2 с): модель 2,07 м, наивная экстраполяция 3,56 м. Выстрел в ближайшие 0,25 с: ROC AUC 0,88.
Готовая страница: `donk_dust2.html`.

## Бот для локального сервера (bot/)

`bot/DonkAI_v0.2.zip` — плагин CounterStrikeSharp + модель + инструкция по установке на свой сервер CS2 (Windows).
Модель в боте — классификатор намерения (`intent.py`): стоять или идти в одну из 8 сторон в ближайшие 2 с,
без признаков скорости и истории (иначе модель копирует инерцию и не трогается со спавна).
Точность намерения на отложенных матчах 58% (частый класс 44%, «идёт как шёл» 47%).
`bot/sim` — 2D-симуляция тех же «мозга и ног» по сетке проходимости из демок; `bot/sim.png` — результат.
Сборка: `dotnet build -c Release` в `bot/src` (.NET 10, CounterStrikeSharp.API 1.0.376); модель `donk_model.json` генерирует `python3 intent.py export`.

## v0.2

- Данные: 70 матчей на Dust2 из архивов на Hugging Face (`extract_all.py`, `features_all.py`), 5 из них с donk.
- «Мозг» (`train_intent_v2b.py`): без признака оружия (профи бегут с ножом в начале раунда, боты — с винтовкой; модель путала ситуации). Точность на отложенном матче с donk 57%.
- Прицел (`look.py`, `train_v2.py`): 36 секторов по 10° + наклон; попадание в направление взгляда donk в пределах 15° — 70% (идти и смотреть по ходу — 23%).
- Бот: общий класс `Brain` (плагин и симуляция), проверка проходимости направления, блокировка тупиков, остановка при виде врага, заранее наводится на врага, которого видят союзники.

## v0.3: тест-стенд и двухслойный бот

- `bot/scen/` — 2D-стенд Dust2 (стены, высоты, зоны, типичное положение союзников — из демок): 17 сценариев + 300 случайных стартов. `analyze_scen.py` сравнивает поведение с реальными игроками.
- `test_factors.py` — реакция модели на факторы (враг рядом, HP, клатч, бомба, время) против реальных игроков в тех же зонах.
- `spot_study.py` — насколько отметка движка «кем замечен» опережает выстрелы donk и его реакция по дистанциям.
- Итог: сценарии 11/17 (v0.2) → 15/17 (v0.3), реакции 5/7 → 6/7. Отчёт: `tests/testbench.html`.
- Бот v0.3: `Brain3` (стратегия: зона через 10 с, `train_strat.py`) + `Brain` (стоять/сдвигаться), признаки бомбы и времени после закладки, многоканальный детектор боя, лог `fights_*.csv`.
