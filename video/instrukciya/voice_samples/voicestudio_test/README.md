# Проба VoiceStudio (debpalash/VoiceStudio, v0.5.7) — 22.10.2026

Запуск: бэкенд VoiceStudio на CPU (4 ядра, без GPU), движок VoxCPM2 (openbmb/VoxCPM2, Apache-2.0 — коммерческое использование разрешено).

- `voxcpm2_ru_golos_po_opisaniyu.mp3` — голос создан по описанию («тёплая спокойная молодая женщина»), без образца. Whisper распознал текст без ошибок.
- `voxcpm2_ru_klon_diktora_F1.mp3` — клон голоса диктора F1 из ISSAI KazakhTTS (CC BY 4.0) по 9-секундному фрагменту, говорит по-русски. Есть ошибки произношения («Шаг первый», «QR-кодом»).

Важно: движок по умолчанию OmniVoice (единственный с казахским) — лицензия весов CC-BY-NC + Higgs Audio 2 + Llama 3, то есть некоммерческая. Для рекламы/озвучки бизнеса не подходит.
Скорость на этом CPU: ~30 с вычислений на 1 с речи (с GPU NVIDIA — в разы быстрее).
VoiceStudio по умолчанию встраивает в аудио невидимый AI-водяной знак (AudioSeal).
