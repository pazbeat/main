# Пробы озвучки (ElevenLabs) и образец для клона казахского голоса

- `ru_full_v4_Kari.mp3` — русская озвучка новой короткой инструкции (eleven_v4, голос Kari, language ru).
- `test_ru_v4_*.mp3`, `test_kk_v3/v4_Aizhan.mp3` — короткие пробы моделей и голосов.
- `kk_clone_sample_ISSAI_F1.mp3` — ~2 мин речи диктора F1 из открытого корпуса ISSAI KazakhTTS
  (Nazarbayev University, лицензия CC BY 4.0; записан профессиональными дикторами для синтеза речи).
  Для Instant Voice Clone в ElevenLabs. Атрибуция: Mussakhojayeva S., Khassanov Y., Varol H.A.,
  "KazakhTTS2: Extending the Open-Source Kazakh TTS Corpus With More Data, Speakers, and Topics", LREC 2022.
