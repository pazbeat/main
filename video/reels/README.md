# Рекламный ролик для Reels — imbir.kz

`imbir_reels_ru.mp4` — 24,5 с, 1080×1920 (9:16), 30 fps. Обложка: `imbir_reels_ru_oblozhka.jpg`.

Кадры: видео атмосферы салонов с сайта (лепестки, массаж, хаммам, лаунж, свечи, полотенце),
запись конструктора на телефоне, веер новых открыток с сайта (/uploads/designs), финальный экран с логотипом.
Музыка — синтезирована локально (`source/music.py`), без внешних сервисов и лицензий.
Сборка: `source/reel.html` (покадровый композитор, рендер через Playwright, `source/render.js`).

## Версия 2 — «Останови видео»
`imbir_reels_ru_v2.mp4` — 23,5 с, 1080×1920. Интерактивный формат: 37 открыток сайта мелькают в ритм
(16-я доля = 4 кадра при 112,5 BPM), остановка на «Отменяй все планы», затем открытки «Она 10/10…»,
«Тайм-аут супермамы», «Дедлайн закрыт», «Он 10/10…» раскрываются в видео салона; стена открыток
«Что выпало тебе? Пиши в комментариях» и призыв «Подари отдых, а не вещь · imbir.kz».
Музыка синтезирована (`source/music2.py`) и синхронизирована с монтажом.

## Версия 3 — «Уведомления → Не беспокоить»
`imbir_reels_ru_v3.mp4` — 22,5 с. Экран блокировки заваливают уведомления (начальник, мама, чат класса,
Kaspi, дедлайн, «где мои носки»), пинги и вибрация ускоряются, «Знакомо?». Свайп — всё улетает,
включается «Не беспокоить · Imbir Thai Spa · 90 мин». Тишина, вода, кадры салона: «Ни звонков.»
«Ни чатов.» «Только ты.» «90 минут тишины». Финал: «Подари кому-то режим „Не беспокоить“» · imbir.kz.
Звук синтезирован и синхронизирован с появлением каждого уведомления (`source/music3.py`).
