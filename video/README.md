# Промо-видео imbir.kz

## Кино-версия — `imbir_film.mp4`

1920×1080, 30 fps, 1:02, монтаж в ритм музыки (96 BPM). Без скриншотов сайта:
золотые частицы собираются в цветок имбиря → логотип; слово «ТАИЛАНД» с видео внутри букв и пролётом сквозь букву;
ритмичный монтаж («Тишина», «Тепло», «Мастера из Таиланда», «Хаммам», «Ритуалы», «Гармония»);
светящаяся карта Казахстана с 7 городами; 3D-сертификаты (реальные дизайны сайта + фирменный с QR-кодом на imbir.kz);
вращающееся кольцо программ; финал с проявлением надписей «золотыми чернилами».
Исходники: `source/film.html`, `source/render2.js`, `source/music2.py`.

## Первая версия — `imbir_promo.mp4`

`imbir_promo.mp4` — презентационный ролик сайта [imbir.kz](https://www.imbir.kz) (1920×1080, 30 fps, 1:16, со звуком).

Сцены: логотип → «Таиланд начинается здесь» (приветственное видео сайта) → мастера и цифры (9 салонов, 7 городов, 20+ программ) → атмосфера салонов → популярные программы и цены → подарочные сертификаты → 6 шагов оформления на сайте → сертификат на email / мобильная версия → салоны в 7 городах → финал с адресом сайта и телефоном.

Все фото, видео и скриншоты взяты с самого сайта. Музыка синтезирована (`source/music.py`), голос в начале — из приветственного ролика сайта.

## Исходники

- `source/promo.html` — анимация (HTML/CSS/JS, функция `seek(t)` рисует кадр на момент `t`)
- `source/render.js` — покадровый рендер через Playwright + ffmpeg
- `source/music.py` — генерация музыки и сведение с голосом

Для пересборки рядом с `promo.html` нужны папки `a/` (медиа с сайта), `frames/` (кадры роликов), `shots/` (скриншоты сайта) и `fonts/`.
